# Blue Launch

Landing de Medusa IV, proyecto escolar de Blue Launch para Rocket Tec Sinaloa 2026. Incluye bitácora, despiece, túnel de viento y simulador con cuenta regresiva.

## Abrir en tu computadora

Descomprime el ZIP y abre `index.html` en tu navegador. El sonido se habilita al pulsar «Activar sonido» o al iniciar la primera cuenta regresiva. Puedes silenciarlo desde el encabezado.

## Publicar en GitHub Pages

1. Descomprime el ZIP y sube su contenido al repositorio. Conserva `assets/` junto a `index.html`, `styles.css` y `app.js`. Si tu sitio ya usa la carpeta `docs/`, puedes subir todo allí.
2. En el repositorio, entra en **Settings → Pages**. Selecciona **Deploy from a branch**.
3. Selecciona tu rama (normalmente `main`) y la carpeta donde quedó `index.html`, ya sea **/(root)** o **/docs**. Guarda la configuración.
4. Cuando termine la publicación, abre el enlace desde **Settings → Pages**.

Las rutas a las imágenes, estilos y scripts son relativas. El sitio no necesita npm ni una compilación. Los valores del simulador son ilustrativos y se calculan en el navegador.
